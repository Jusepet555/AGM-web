# AGM · Fusteria exterior i tancaments

Web estàtica en català. Obre `index.html` per previsualitzar-la.

## Publicació amb GitHub Pages

1. Descomprimeix el ZIP i posa el contingut de la carpeta del web a l’arrel d’un repositori de GitHub. El fitxer `index.html` ha de quedar al mateix nivell que `estils.css`, `web.js` i la carpeta `imatges/`.
2. Al repositori, entra a **Settings → Pages**. A **Source**, tria **Deploy from a branch**.
3. Selecciona la branca **main** i la carpeta **/(root)**, i desa. GitHub mostrarà l’enllaç quan s’acabi el desplegament.

Les imatges dels serveis i de la portada són recreacions fotogràfiques generades per a la web. Es poden substituir per fotografies pròpies conservant els noms dels fitxers. El logotip prové de l’arxiu original d’AGM.

Els enllaços de contacte obren l’aplicació de trucades i el client de correu del visitant. Les fitxes dels serveis funcionen al navegador.
